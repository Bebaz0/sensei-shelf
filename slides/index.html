One confidence-aware decision. Probabilities in, the answer with the best expected score out. When the evidence is uncertain, it takes the cheaper mistake.
So how do we know these recommendations are worth acting on? We don't rely on a single model making a guess. TrustyShelf combines several sources of evidence: visual features extracted directly from the images, similarities to previously labelled shelf observations, changes over time, and vision-language models that compare products against the expected shelf contents. These signals are combined into a confidence-aware decision system. When the evidence is uncertain, the system can use additional analysis rather than blindly trusting its first prediction. And we evaluate the result against labelled examples using the same scoring rules as the challenge, where false alarms and missed stock problems have different costs.
